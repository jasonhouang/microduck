# 安全机制

## 概述

Microduck 的安全机制是系统的核心保障，确保机器人在各种异常情况下不会损坏自身或伤害用户。安全机制贯穿整个系统，从硬件层到应用层，形成多层防护。

## 1. 摔倒检测与保护

### 摔倒检测算法

```rust
struct FallDetector {
    tilt_threshold: f32,        // 倾斜阈值 (rad)
    angular_vel_threshold: f32, // 角速度阈值 (rad/s)
    height_threshold: f32,      // 高度阈值 (m)
    debounce_count: u32,        // 去抖计数
    current_count: u32,         // 当前计数
}

impl FallDetector {
    fn new() -> Self {
        Self {
            tilt_threshold: 0.8,        // ~45°
            angular_vel_threshold: 5.0, // rad/s
            height_threshold: 0.1,      // 10cm
            debounce_count: 3,          // 连续 3 次检测
            current_count: 0,
        }
    }
    
    fn detect(&mut self, sensors: &Sensors) -> bool {
        let mut fall_detected = false;
        
        // 1. 检查倾斜角度
        let tilt = sensors.imu.gravity.angle_to([0.0, 0.0, -1.0]);
        if tilt > self.tilt_threshold {
            fall_detected = true;
        }
        
        // 2. 检查角速度（快速旋转）
        let angular_vel = sensors.imu.gyro.norm();
        if angular_vel > self.angular_vel_threshold {
            fall_detected = true;
        }
        
        // 3. 检查高度（通过加速度积分估算）
        if sensors.estimated_height < self.height_threshold {
            fall_detected = true;
        }
        
        // 4. 去抖处理
        if fall_detected {
            self.current_count += 1;
            if self.current_count >= self.debounce_count {
                return true;
            }
        } else {
            self.current_count = 0;
        }
        
        false
    }
}
```

```rust
        match self.state {
            FallProtectionState::Normal => {

                    self.state = FallProtectionState::Falling;
                    self.fall_start = Some(Instant::now());
                    
                    // 立即执行保护动作
                    self.enter_protection_pose(targets);

                self.maintain_protection_pose(targets);
                
                // 检查是否可以开始恢复
                if let Some(start) = self.fall_start {
                    if start.elapsed() > Duration::from_millis(500) {
                        self.state = FallProtectionState::Recovering;
                    }
                }

            FallProtectionState::Recovering => {
                // 逐步恢复到站立姿势
```

## 2. 关节保护

### 关节限位检查

```rust
struct JointLimits {
    min_angle: f32,   // 最小角度 (rad)
    max_angle: f32,   // 最大角度 (rad)
    max_velocity: f32, // 最大速度 (rad/s)
    max_torque: f32,   // 最大扭矩 (Nm)
}

const JOINT_LIMITS: [JointLimits; 15] = [
    // 左腿
    JointLimits { min_angle: -0.5, max_angle: 0.5, max_velocity: 5.0, max_torque: 2.0 },  // hip_yaw
    JointLimits { min_angle: -0.8, max_angle: 0.8, max_velocity: 5.0, max_torque: 2.0 },  // hip_roll
    JointLimits { min_angle: -1.2, max_angle: 0.5, max_velocity: 5.0, max_torque: 2.0 },  // hip_pitch
    JointLimits { min_angle: 0.0, max_angle: 2.0, max_velocity: 5.0, max_torque: 2.0 },   // knee
    JointLimits { min_angle: -0.8, max_angle: 0.8, max_velocity: 5.0, max_torque: 2.0 },  // ankle
    // ... 其他关节
];

fn check_joint_limits(targets: &mut JointTargets, sensors: &Sensors) {
    for i in 0..15 {
        let limits = &JOINT_LIMITS[i];
        
        // 1. 角度限位
        if targets[i] < limits.min_angle {
            targets[i] = limits.min_angle;
        } else if targets[i] > limits.max_angle {
            targets[i] = limits.max_angle;
        }
        
        // 2. 速度限制
        let current_pos = sensors.joint_pos[i];
        let velocity = (targets[i] - current_pos) / 0.02; // 50Hz
        if velocity.abs() > limits.max_velocity {
            let max_delta = limits.max_velocity * 0.02;
            targets[i] = current_pos + velocity.signum() * max_delta;
        }
    }
}
```

### 碰撞检测

```rust
struct CollisionDetector {
    expected_torque: [f32; 15],
    tolerance: f32,  // 扭矩偏差容忍度
}

impl CollisionDetector {
    fn detect(&mut self, sensors: &Sensors, targets: &JointTargets) -> bool {
        for i in 0..15 {
            let actual_torque = sensors.joint_torque[i];
            let expected = self.expected_torque[i];
            
            // 如果实际扭矩远大于预期，可能发生碰撞
            if (actual_torque - expected).abs() > self.tolerance {
                tracing::warn!(
                    joint = i,
                    actual = actual_torque,
                    expected = expected,
                    "Collision detected"
                );
                return true;
            }
        }
        false
    }
    
    fn update_expected(&mut self, targets: &JointTargets, sensors: &Sensors) {
        // 根据目标位置和当前状态估算预期扭矩
        // 使用简化的动力学模型
        for i in 0..15 {
            self.expected_torque[i] = estimate_torque(targets[i], sensors.joint_pos[i]);
        }
    }
}
```

## 3. 电池保护

### 电压监测

```rust
struct BatteryMonitor {
    voltage_history: VecDeque<f32>,
    low_voltage_threshold: f32,    // 低压阈值 (V)
    critical_voltage_threshold: f32, // 危急阈值 (V)
    window_size: usize,
}

impl BatteryMonitor {
    fn new() -> Self {
        Self {
            voltage_history: VecDeque::with_capacity(100),
            low_voltage_threshold: 7.0,    // 20% 电量
            critical_voltage_threshold: 6.6, // 0% 电量
            window_size: 50,
        }
    }
    
    fn update(&mut self, voltage: f32) -> BatteryState {
        self.voltage_history.push_back(voltage);
        if self.voltage_history.len() > self.window_size {
            self.voltage_history.pop_front();
        }
        
        // 计算平均电压（去噪）
        let avg_voltage = self.average_voltage();
        
        if avg_voltage < self.critical_voltage_threshold {
            BatteryState::Critical
        } else if avg_voltage < self.low_voltage_threshold {
            BatteryState::Low
        } else {
            BatteryState::Normal
        }
    }
    
    fn average_voltage(&self) -> f32 {
        if self.voltage_history.is_empty() {
            return 0.0;
        }
        let sum: f32 = self.voltage_history.iter().sum();
        sum / self.voltage_history.len() as f32
    }
}

enum BatteryState {
    Normal,
    Low,
    Critical,
}
```

### 低电量保护策略

```rust
struct BatteryProtection {
    state: BatteryState,
    low_battery_time: Option<Instant>,
}

impl BatteryProtection {
    fn update(&mut self, state: BatteryState, targets: &mut JointTargets, sensors: &Sensors) {
        match state {
            BatteryState::Normal => {
                self.low_battery_time = None;
            }
            BatteryState::Low => {
                // 限制运动速度，节省电量
                self.limit_movement(targets);
                
                // 记录低电量开始时间
                if self.low_battery_time.is_none() {
                    self.low_battery_time = Some(Instant::now());
                }
                
                // 如果低电量超过 5 分钟，自动坐下
                if let Some(time) = self.low_battery_time {
                    if time.elapsed() > Duration::from_secs(300) {
                        self.force_sit(targets);
                    }
                }
            }
            BatteryState::Critical => {
                // 立即坐下，切断电源
                self.force_sit(targets);
                self.prepare_shutdown(sensors);
            }
        }
    }
    
    fn limit_movement(&self, targets: &mut JointTargets) {
        // 限制所有关节速度为正常的 50%
        for i in 0..15 {
            let max_delta = 0.5 * MAX_VELOCITY * 0.02;
            let delta = targets[i] - sensors.joint_pos[i];
            if delta.abs() > max_delta {
                targets[i] = sensors.joint_pos[i] + delta.signum() * max_delta;
            }
        }
    }
    
    fn force_sit(&self, targets: &mut JointTargets) {
        // 强制坐下姿势
        targets.left_hip_pitch = -0.8;
        targets.left_knee = 1.5;
        targets.left_ankle = -0.7;
        
        targets.right_hip_pitch = -0.8;
        targets.right_knee = 1.5;
        targets.right_ankle = -0.7;
    }
    
    fn prepare_shutdown(&self, sensors: &Sensors) {
        // 保存状态到持久化存储
        save_state(sensors);
        
        // 发送关机信号
        send_shutdown_signal();
    }
}
```

## 4. 舵机保护

### 过流保护

```rust
struct OvercurrentProtection {
    current_threshold: f32,     // 电流阈值 (A)
    duration_threshold: Duration, // 持续时间阈值
    violation_start: Option<Instant>,
}

impl OvercurrentProtection {
    fn check(&mut self, sensors: &Sensors) -> bool {
        let max_current = sensors.joint_current.iter().cloned().fold(0.0, f32::max);
        
        if max_current > self.current_threshold {
            if self.violation_start.is_none() {
                self.violation_start = Some(Instant::now());
            }
            
            if let Some(start) = self.violation_start {
                if start.elapsed() > self.duration_threshold {
                    tracing::error!(
                        current = max_current,
                        threshold = self.current_threshold,
                        "Overcurrent detected"
                    );
                    return true;
                }
            }
        } else {
            self.violation_start = None;
        }
        
        false
    }
}
```

### 过热保护

```rust
struct OverheatProtection {
    temperature_threshold: f32,  // 温度阈值 (°C)
    hysteresis: f32,             // 迟滞值 (°C)
    overheated: [bool; 15],      // 每个关节的过热状态
}

impl OverheatProtection {
    fn check(&mut self, sensors: &Sensors, targets: &mut JointTargets) {
        for i in 0..15 {
            let temp = sensors.joint_temperature[i];
            
            if !self.overheated[i] && temp > self.temperature_threshold {
                // 进入过热状态
                self.overheated[i] = true;
                tracing::warn!(joint = i, temperature = temp, "Joint overheated");
                
                // 限制该关节的运动
                targets[i] = sensors.joint_pos[i]; // 保持当前位置
            } else if self.overheated[i] && temp < self.temperature_threshold - self.hysteresis {
                // 退出过热状态（带迟滞）
                self.overheated[i] = false;
                tracing::info!(joint = i, temperature = temp, "Joint cooled down");
            }
        }
    }
}
```

### 超时保护

```rust
struct CommunicationWatchdog {
    last_command_time: Instant,
    timeout: Duration,
}

impl CommunicationWatchdog {
    fn check(&mut self) -> bool {
        if self.last_command_time.elapsed() > self.timeout {
            tracing::warn!("Communication timeout");
            return true;
        }
        false
    }
    
    fn on_command_received(&mut self) {
        self.last_command_time = Instant::now();
    }
    
    fn on_timeout(&self, targets: &mut JointTargets, sensors: &Sensors) {
        // 通信超时，停止所有运动
        for i in 0..15 {
            targets[i] = sensors.joint_pos[i]; // 保持当前位置
        }
    }
}
```

### 指令验证

```rust
struct CommandValidator {
    max_velocity: f32,      // 最大速度指令
    max_acceleration: f32,  // 最大加速度指令
}

impl CommandValidator {
    fn validate(&self, command: &Command, last_command: &Command, dt: f32) -> bool {
        // 1. 检查速度范围
        if command.vx.abs() > self.max_velocity
            || command.vy.abs() > self.max_velocity
            || command.vyaw.abs() > self.max_velocity
        {
            tracing::warn!("Command velocity out of range");
            return false;
        }
        
        // 2. 检查加速度（防止突变）
        let dvx = (command.vx - last_command.vx) / dt;
        let dvy = (command.vy - last_command.vy) / dt;
        let dvyaw = (command.vyaw - last_command.vyaw) / dt;
        
        if dvx.abs() > self.max_acceleration
            || dvy.abs() > self.max_acceleration
            || dvyaw.abs() > self.max_acceleration
        {
            tracing::warn!("Command acceleration too high");
            return false;
        }
        
        true
    }
}
```

```rust
struct HealthMonitor {
    checks: Vec<HealthCheck>,

struct HealthCheck {
    name: String,
    check_fn: Box<dyn Fn(&Sensors) -> bool>,
    critical: bool,
}

impl HealthMonitor {
    fn check(&self, sensors: &Sensors) -> HealthStatus {
        let mut status = HealthStatus::Healthy;
        
        for check in &self.checks {
            if !(check.check_fn)(sensors) {
                if check.critical {
                    status = HealthStatus::Critical;
                    tracing::error!(check = %check.name, "Critical health check failed");
                    break;
                } else {
                    status = HealthStatus::Degraded;
                    tracing::warn!(check = %check.name, "Health check failed");
                }
            }
        }
        
        status
    }
}

enum HealthStatus {
    Healthy,
    Degraded,
    Critical,
}
```

```rust
struct PerformanceMonitor {
    cycle_times: VecDeque<Duration>,
    max_cycle_time: Duration,
    missed_cycles: u64,
}

impl PerformanceMonitor {
    fn record_cycle(&mut self, cycle_time: Duration, missed: bool) {
        self.cycle_times.push_back(cycle_time);
        if self.cycle_times.len() > 1000 {
            self.cycle_times.pop_front();
        }
        
        self.max_cycle_time = self.max_cycle_time.max(cycle_time);
        
        if missed {
            self.missed_cycles += 1;
        }
    }
    
    fn average_cycle_time(&self) -> Duration {
        if self.cycle_times.is_empty() {
            return Duration::ZERO;
        }
        let sum: Duration = self.cycle_times.iter().sum();
        sum / self.cycle_times.len() as u32
    }
    
    fn report(&self) {
        tracing::info!(
            avg_cycle_ms = self.average_cycle_time().as_millis(),
            max_cycle_ms = self.max_cycle_time.as_millis(),
            missed_cycles = self.missed_cycles,
            "Performance report"
        );
    }
}
```

## 8. 安全状态机

```rust
enum SafetyState {
    Normal,
    Warning,
    Critical,
    Emergency,
}

struct SafetyStateMachine {
    state: SafetyState,
    fall_detector: FallDetector,
    battery_monitor: BatteryMonitor,
    collision_detector: CollisionDetector,
    overcurrent_protection: OvercurrentProtection,
    overheat_protection: OverheatProtection,
    comm_watchdog: CommunicationWatchdog,
    emergency_stop: EmergencyStop,
}

impl SafetyStateMachine {
    fn update(&mut self, sensors: &Sensors, targets: &mut JointTargets) {
        // 1. 紧急停止检查（最高优先级）
        if self.emergency_stop.check() {
            self.state = SafetyState::Emergency;
            self.emergency_stop.on_emergency_stop(targets, sensors);
            return;
        }
        
        // 2. 摔倒检测
        if self.fall_detector.detect(sensors) {
            self.state = SafetyState::Critical;
            self.fall_protection.on_fall(targets);
            return;
        }
        
        // 3. 电池检查
        let battery_state = self.battery_monitor.update(sensors.battery_voltage);
        if matches!(battery_state, BatteryState::Critical) {
            self.state = SafetyState::Critical;
            self.battery_protection.on_critical(targets, sensors);
            return;
        }
        
        // 4. 碰撞检测
        if self.collision_detector.detect(sensors, targets) {
            self.state = SafetyState::Warning;
            self.collision_protection.on_collision(targets);
        }
        
        // 5. 过流检查
        if self.overcurrent_protection.check(sensors) {
            self.state = SafetyState::Critical;
            self.overcurrent_protection.on_overcurrent(targets);
            return;
        }
        
        // 6. 过热检查
        self.overheat_protection.check(sensors, targets);
        
        // 7. 通信检查
        if self.comm_watchdog.check() {
            self.state = SafetyState::Warning;
            self.comm_watchdog.on_timeout(targets, sensors);
        }
        
        // 8. 关节限位检查
        check_joint_limits(targets, sensors);
    }
}
```

## 总结

Microduck 的安全机制是一个多层次、多维度的防护系统：

1. **摔倒检测**: 倾斜角度、角速度、高度三重检测
2. **关节保护**: 限位检查、速度限制、碰撞检测
3. **电池保护**: 电压监测、低电量策略、自动关机
4. **舵机保护**: 过流保护、过热保护
5. **通信安全**: 超时保护、指令验证
6. **系统监控**: 健康检查、性能监控
7. **紧急停止**: 硬件按钮、软件触发

这些安全机制确保机器人在各种异常情况下能够安全停止或进入保护状态，防止损坏和伤害。
