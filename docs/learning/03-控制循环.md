# 控制循环

## 概述

Microduck 的核心是一个 **50Hz 的实时控制循环**，负责读取传感器状态、运行策略推理、计算目标位置、写入舵机。整个循环必须在 **20ms** 内完成，错过周期立即丢弃，不补发。

## 控制循环架构

```
┌─────────────────────────────────────────────────────────┐
│                    50Hz 控制循环                         │
│                                                         │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐         │
│  │ 传感器   │ →  │ 策略推理 │ →  │ 安全过滤 │         │
│  │  读取    │    │  (ONNX)  │    │  (safety)│         │
│  └──────────┘    └──────────┘    └──────────┘         │
│       ↑                                ↓               │
│       │                                │               │
│  ┌──────────┐                    ┌──────────┐         │
│  │ 舵机写入 │ ← ─ ─ ─ ─ ─ ─ ─ ─│ 目标计算 │         │
│  └──────────┘                    └──────────┘         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 时序分析

### 单个周期 (20ms)

```
时间轴: 0ms        2ms        4ms        6ms       20ms
        ├──────────┼──────────┼──────────┼──────────┤
        │ 传感器   │ 策略推理 │ 目标计算 │  余量    │
        │  读取    │  (ONNX)  │ 安全过滤 │          │
        │  (2ms)   │  (2ms)   │  (2ms)   │  (14ms)  │
        └──────────┴──────────┴──────────┴──────────┘
```

### 详细时序

**1. 传感器读取 (2ms)**
```rust
// 一次 sync_read 读取 16 个设备 (1 IMU + 15 舵机)
let sensors = io.read()?;

// 返回数据:
// - IMU: 陀螺仪 (3) + 四元数 (4) + 重力 (3)
// - 舵机: 位置 (15) + 速度 (15) + 电流 (15) + 温度 (15)
```

**2. 策略推理 (2ms)**
```rust
// 构建 observation 向量 (61 维)
let obs = Observation::build(&sensors, &command);

// ONNX 推理
let action = policy.infer(&obs)?;  // 返回 14 维 action
```

**3. 目标计算 (1ms)**
```rust
// action → 关节目标
let targets = compute_targets(&action, &sensors);
```

**4. 安全过滤 (1ms)**
```rust
// 安全检查 + 限制
let safe_targets = safety.apply(targets, &sensors);
```

**5. 舵机写入 (2ms)**
```rust
// 一次 sync_write 写入 15 个舵机
io.write(&safe_targets)?;
```

**6. 等待 (12ms)**
```rust
// 等待下一个周期
let elapsed = start.elapsed();
if elapsed < PERIOD {
    sleep(PERIOD - elapsed);
}
```

## Observation 向量

## 策略系统

### 策略类型

Microduck 使用多个 ONNX 策略，每个策略负责特定行为：

```
policies/
├── walking.onnx       # 行走策略
├── standing.onnx      # 站立策略
├── sitting.onnx       # 坐下策略
├── standing_up.onnx   # 站起策略
├── kicking.onnx       # 踢球策略
├── picking.onnx       # 捡东西策略
└── falling.onnx       # 摔倒恢复策略
```

### 策略选择逻辑

```rust
enum PolicyState {
    Walking,
    Standing,
    Sitting,
    StandingUp,
    Kicking,
    Picking,
    Falling,
}

fn select_policy(state: &PolicyState, command: &Command) -> &str {
    match state {
        PolicyState::Falling => "falling.onnx",
        PolicyState::Kicking => "kicking.onnx",
        PolicyState::Picking => "picking.onnx",
        PolicyState::Sitting => "sitting.onnx",
        PolicyState::StandingUp => "standing_up.onnx",
        _ => {
            if command.is_moving() {
                "walking.onnx"
            } else {
                "standing.onnx"
            }
        }
    }
}
```

## 目标计算

### 逆运动学 (IK)

策略输出的是关节角度，但需要转换为舵机目标位置：

```rust
fn compute_targets(action: &Array1<f32>, sensors: &Sensors) -> JointTargets {
    let mut targets = JointTargets::default();
    
    // 左腿
    for i in 0..5 {
        targets.left_leg[i] = action[i];
    }
    
    // 右腿
    for i in 0..5 {
        targets.right_leg[i] = action[5 + i];
    }
    
    // 头部
    for i in 0..4 {
        targets.head[i] = action[10 + i];
    }
    
    // 嘴（不参与策略）
    targets.mouth = sensors.mouth_position;
    
    targets
}
```

### 平滑滤波

为避免抖动，对目标位置进行低通滤波：

```rust
struct LowPassFilter {
    alpha: f32,      // 滤波系数 (0.0 ~ 1.0)
    state: [f32; 15],
}

impl LowPassFilter {
    fn filter(&mut self, input: &[f32; 15]) -> [f32; 15] {
        let mut output = [0.0; 15];
        for i in 0..15 {
            output[i] = self.alpha * input[i] 
                      + (1.0 - self.alpha) * self.state[i];
            self.state[i] = output[i];
        }
        output
    }
}
```

## 安全机制

### 安全检查

```rust
struct Safety {
    max_joint_velocity: f32,    // 最大关节速度 (rad/s)
    max_tilt_angle: f32,        // 最大倾斜角度 (rad)
    min_battery_voltage: f32,   // 最低电池电压 (V)
}

impl Safety {
    fn apply(&self, targets: &JointTargets, sensors: &Sensors) -> Result<JointTargets> {
        // 1. 检查电池电压
        if sensors.battery_voltage < self.min_battery_voltage {
            return Err(SafetyError::LowBattery);
        }
        
        // 2. 检查倾斜角度
        let tilt = sensors.imu.gravity.angle_to([0.0, 0.0, -1.0]);
        if tilt > self.max_tilt_angle {
            return Err(SafetyError::TooTilted);
        }
        
        // 3. 限制关节速度
        let mut safe_targets = targets.clone();
        for i in 0..15 {
            let velocity = (targets[i] - sensors.joint_pos[i]) / 0.02; // 50Hz
            if velocity.abs() > self.max_joint_velocity {
                safe_targets[i] = sensors.joint_pos[i] 
                    + velocity.signum() * self.max_joint_velocity * 0.02;
            }
        }
        
        Ok(safe_targets)
    }
}
```

### 摔倒检测

```rust
fn detect_fall(sensors: &Sensors) -> bool {
    // 1. 检查倾斜角度
    let tilt = sensors.imu.gravity.angle_to([0.0, 0.0, -1.0]);
    if tilt > 0.8 {  // ~45 度
        return true;
    }
    
    // 2. 检查角速度
    let angular_vel = sensors.imu.gyro.norm();
    if angular_vel > 5.0 {  // rad/s
        return true;
    }
    
    // 3. 检查高度（通过加速度积分）
    if sensors.estimated_height < 0.1 {  // 10cm
        return true;
    }
    
    false
}
```

### 状态管理

```rust
struct StateMachine {
    state: PolicyState,
    transition_time: Instant,
}

impl StateMachine {
    fn update(&mut self, command: &Command, sensors: &Sensors) {
        // 摔倒检测（最高优先级）
        if detect_fall(sensors) {
            self.state = PolicyState::Falling;
            self.transition_time = Instant::now();
            return;
        }
        
        // 状态转换逻辑
        match self.state {
            PolicyState::Standing => {
                if command.is_moving() {
                    self.state = PolicyState::Walking;
                } else if command.sit {
                    self.state = PolicyState::Sitting;
                }
            }
            PolicyState::Walking => {
                if !command.is_moving() {
                    self.state = PolicyState::Standing;
                }
            }
            PolicyState::Sitting => {
                if command.stand_up {
                    self.state = PolicyState::StandingUp;
                }
            }
            PolicyState::StandingUp => {
                if self.transition_time.elapsed() > Duration::from_secs(2) {
                    self.state = PolicyState::Standing;
                }
            }
            PolicyState::Falling => {
                if self.transition_time.elapsed() > Duration::from_secs(3) {
                    self.state = PolicyState::Standing;
                }
            }
            _ => {}
        }
    }
}
```

```rust
struct PerformanceMonitor {
    periods: VecDeque<Duration>,
    max_period: Duration,
}

impl PerformanceMonitor {
    fn record(&mut self, period: Duration) {
        self.periods.push_back(period);
        if self.periods.len() > 100 {
            self.periods.pop_front();
        }
        self.max_period = self.max_period.max(period);
    }
    
    fn average(&self) -> Duration {
        let sum: Duration = self.periods.iter().sum();
        sum / self.periods.len() as u32
    }
}
```

## 总结

Microduck 的控制循环是一个精心设计的实时系统：

1. **50Hz 硬实时**: 20ms 周期，错过即丢弃
2. **传感器融合**: IMU + 舵机反馈，构建完整状态
3. **策略推理**: 多个 ONNX 模型，状态机切换
4. **安全保护**: 多层检查，防止损坏
5. **性能优化**: 预分配、零拷贝、并行计算

这个控制循环是 Microduck 能够稳定行走、完成复杂动作的核心。
