# 部署流程

## 概述

Microduck 的部署流程涵盖了从开发环境搭建、交叉编译、固件打包、签名验证到最终部署到机器人的完整流程。本文档将详细介绍每个步骤，帮助开发者快速上手。

## 1. 开发环境搭建

### 系统要求

- **操作系统**: Linux (推荐 Ubuntu 20.04+) 或 macOS
- **Rust**: 1.70.0 或更高版本
- **交叉编译工具链**: 用于编译 ARM64 目标
- **依赖库**: OpenSSL, pkg-config

### 安装 Rust

```bash
# 安装 rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 选择默认安装
source $HOME/.cargo/env

# 验证安装
rustc --version
cargo --version
```

### 安装交叉编译工具链

#### Linux (Ubuntu/Debian)

```bash
# 安装 AArch64 交叉编译工具链
sudo apt-get update
sudo apt-get install -y gcc-aarch64-linux-gnu g++-aarch64-linux-gnu

# 安装交叉编译所需的库
sudo apt-get install -y \
    libssl-dev:arm64 \
    pkg-config \
    cmake

# 配置 Cargo 使用交叉编译器
mkdir -p ~/.cargo
cat >> ~/.cargo/config.toml << EOF
[target.aarch64-unknown-linux-gnu]
linker = "aarch64-linux-gnu-gcc"
EOF
```

#### macOS

```bash
# 安装 Homebrew（如果未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装交叉编译工具链
brew install messense/macos-cross-toolchains/aarch64-unknown-linux-gnu

# 配置 Cargo
mkdir -p ~/.cargo
cat >> ~/.cargo/config.toml << EOF
[target.aarch64-unknown-linux-gnu]
linker = "aarch64-unknown-linux-gnu-gcc"
EOF
```

### 添加 Rust 目标

```bash
# 添加 ARM64 目标
rustup target add aarch64-unknown-linux-gnu

# 验证
rustup target list | grep aarch64
```

### 安装项目依赖

```bash
# 克隆项目
git clone https://github.com/microduck-robotics/microduck.git
cd microduck

# 构建项目（检查依赖）
cargo build
```

## 3. 构建流程

### 开发构建

```bash
# 构建所有组件（调试模式）
cargo build

# 构建特定组件
cargo build -p robotd
cargo build -p mediad

# 运行测试
cargo test

# 运行特定测试
cargo test -p duck-control
```

### 发布构建

```bash
# 构建发布版本（优化模式）
cargo build --release

# 交叉编译为 ARM64
cargo build --release --target aarch64-unknown-linux-gnu
```

### 构建脚本

创建 `scripts/build-release.sh`：

```bash
#!/bin/bash
set -e

echo "Building release version for ARM64..."

# 清理旧的构建
cargo clean

# 设置环境变量
export CARGO_PROFILE_RELEASE_LTO=true
export CARGO_PROFILE_RELEASE_CODEGEN_UNITS=1

# 构建
cargo build --release --target aarch64-unknown-linux-gnu

echo "Build completed successfully!"
echo "Binaries located in: target/aarch64-unknown-linux-gnu/release/"

# 列出构建的二进制文件
ls -lh target/aarch64-unknown-linux-gnu/release/ | grep -E 'robotd|mediad|configd|padd|btd|updaterd|robotctl'
```

## 4. 固件打包

### 打包脚本

创建 `scripts/package-update.sh`：

```bash
#!/bin/bash
set -e

VERSION=$1
if [ -z "$VERSION" ]; then
    echo "Usage: $0 <version>"
    echo "Example: $0 1.2.3"
    exit 1
fi

echo "Packaging update v${VERSION}..."

# 创建临时目录
PACKAGE_DIR="update-v${VERSION}"
rm -rf "$PACKAGE_DIR"
mkdir -p "$PACKAGE_DIR"

# 复制二进制文件
BIN_DIR="target/aarch64-unknown-linux-gnu/release"
cp "$BIN_DIR/robotd" "$PACKAGE_DIR/"
cp "$BIN_DIR/mediad" "$PACKAGE_DIR/"
cp "$BIN_DIR/configd" "$PACKAGE_DIR/"
cp "$BIN_DIR/padd" "$PACKAGE_DIR/"
cp "$BIN_DIR/btd" "$PACKAGE_DIR/"
cp "$BIN_DIR/updaterd" "$PACKAGE_DIR/"
cp "$BIN_DIR/robotctl" "$PACKAGE_DIR/"

# 复制策略文件
mkdir -p "$PACKAGE_DIR/policies"
cp policies/*.onnx "$PACKAGE_DIR/policies/"

# 复制配置文件
mkdir -p "$PACKAGE_DIR/config"
cp config/*.toml "$PACKAGE_DIR/config/"

# 复制 systemd 服务文件
mkdir -p "$PACKAGE_DIR/systemd"
cp systemd/*.service "$PACKAGE_DIR/systemd/"

# 创建 manifest.json
cat > "$PACKAGE_DIR/manifest.json" << EOF
{
  "version": "${VERSION}",
  "timestamp": "$(date -u +%Y-%m-%dT%H:%M:%SZ)",
  "min_supported_version": "1.0.0",
  "changelog": "Update to version ${VERSION}",
  "files": {
    "robotd": {
      "path": "robotd",
      "sha256": "$(sha256sum "$PACKAGE_DIR/robotd" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/robotd"),
      "permissions": "0755"
    },
    "mediad": {
      "path": "mediad",
      "sha256": "$(sha256sum "$PACKAGE_DIR/mediad" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/mediad"),
      "permissions": "0755"
    },
    "configd": {
      "path": "configd",
      "sha256": "$(sha256sum "$PACKAGE_DIR/configd" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/configd"),
      "permissions": "0755"
    },
    "padd": {
      "path": "padd",
      "sha256": "$(sha256sum "$PACKAGE_DIR/padd" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/padd"),
      "permissions": "0755"
    },
    "btd": {
      "path": "btd",
      "sha256": "$(sha256sum "$PACKAGE_DIR/btd" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/btd"),
      "permissions": "0755"
    },
    "updaterd": {
      "path": "updaterd",
      "sha256": "$(sha256sum "$PACKAGE_DIR/updaterd" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/updaterd"),
      "permissions": "0755"
    },
    "robotctl": {
      "path": "robotctl",
      "sha256": "$(sha256sum "$PACKAGE_DIR/robotctl" | cut -d' ' -f1)",
      "size": $(stat -c%s "$PACKAGE_DIR/robotctl"),
      "permissions": "0755"
    }
  },
  "dependencies": {
    "libc": ">=2.31",
    "libssl": ">=1.1.1"
  },
  "restart_required": true,
  "breaking_changes": false
}
EOF

# 创建 tar.gz 包
tar -czf "update-v${VERSION}.tar.gz" "$PACKAGE_DIR"

echo "Package created: update-v${VERSION}.tar.gz"
ls -lh "update-v${VERSION}.tar.gz"

# 清理临时目录
rm -rf "$PACKAGE_DIR"
```

### 使用打包脚本


## 5. 签名验证

### 生成密钥对

```bash
# 生成 Ed25519 密钥对
openssl genpkey -algorithm Ed25519 -out keys/update.key
openssl pkey -in keys/update.key -pubout -out keys/update.pub

# 设置权限
chmod 600 keys/update.key
chmod 644 keys/update.pub
```

### 签名脚本

创建 `scripts/sign-update.sh`：

```bash
#!/bin/bash
set -e

PACKAGE=$1
if [ -z "$PACKAGE" ]; then
    echo "Usage: $0 <package.tar.gz>"
    exit 1
fi

if [ ! -f "$PACKAGE" ]; then
    echo "Package not found: $PACKAGE"
    exit 1
fi

echo "Signing package: $PACKAGE"

# 提取 manifest.json
tar -xzf "$PACKAGE" --wildcards "*/manifest.json"
MANIFEST_DIR=$(tar -tzf "$PACKAGE" | head -1 | cut -d'/' -f1)

# 签名 manifest
openssl dgst -sign keys/update.key -out "${MANIFEST_DIR}/manifest.sig" "${MANIFEST_DIR}/manifest.json"

# 重新打包
tar -czf "${PACKAGE%.tar.gz}-signed.tar.gz" "$MANIFEST_DIR"

echo "Signed package created: ${PACKAGE%.tar.gz}-signed.tar.gz"

# 清理
rm -rf "$MANIFEST_DIR"
```

### 验证脚本

创建 `scripts/verify-update.sh`：

```bash
#!/bin/bash
set -e

PACKAGE=$1
if [ -z "$PACKAGE" ]; then
    echo "Usage: $0 <package-signed.tar.gz>"
    exit 1
fi

echo "Verifying package: $PACKAGE"

# 提取文件
tar -xzf "$PACKAGE"
MANIFEST_DIR=$(tar -tzf "$PACKAGE" | head -1 | cut -d'/' -f1)

# 验证签名
if openssl dgst -verify keys/update.pub -signature "${MANIFEST_DIR}/manifest.sig" "${MANIFEST_DIR}/manifest.json"; then
    echo "✓ Signature verified successfully"
else
    echo "✗ Signature verification failed"
    rm -rf "$MANIFEST_DIR"
    exit 1
fi

# 验证文件完整性
echo "Verifying file integrity..."
cd "$MANIFEST_DIR"

# 读取 manifest.json 并验证每个文件
python3 << EOF
import json
import hashlib
import sys

with open('manifest.json') as f:
    manifest = json.load(f)

errors = []
for name, info in manifest['files'].items():
    path = info['path']
    expected_hash = info['sha256']
    
    with open(path, 'rb') as f:
        actual_hash = hashlib.sha256(f.read()).hexdigest()
    
    if actual_hash != expected_hash:
        errors.append(f"{name}: hash mismatch")
        print(f"✗ {name}: hash mismatch")
    else:
        print(f"✓ {name}: verified")

if errors:
    print(f"\n{len(errors)} file(s) failed verification")
    sys.exit(1)
else:
    print("\nAll files verified successfully")
EOF

cd ..
rm -rf "$MANIFEST_DIR"
```

## 6. 部署到机器人

### 部署脚本

创建 `scripts/deploy.sh`：

```bash
#!/bin/bash
set -e

ROBOT_IP=$1
PACKAGE=$2

if [ -z "$ROBOT_IP" ] || [ -z "$PACKAGE" ]; then
    echo "Usage: $0 <robot-ip> <package-signed.tar.gz>"
    exit 1
fi

echo "Deploying to robot at $ROBOT_IP..."

# 上传更新包
echo "Uploading package..."
scp "$PACKAGE" root@$ROBOT_IP:/tmp/

# 在机器人上执行更新
echo "Installing update..."
ssh root@$ROBOT_IP << EOF
    # 解压更新包
    cd /tmp
    tar -xzf $(basename "$PACKAGE")
    MANIFEST_DIR=\$(tar -tzf $(basename "$PACKAGE") | head -1 | cut -d'/' -f1)
    
    # 停止服务
    systemctl stop robotd mediad configd padd btd
    
    # 备份当前版本
    if [ -d /opt/robot/current ]; then
        cp -r /opt/robot/current /opt/robot/backup-\$(date +%Y%m%d-%H%M%S)
    fi
    
    # 安装新版本
    mkdir -p /opt/robot/releases
    mv "\$MANIFEST_DIR" /opt/robot/releases/v\$(cat "\$MANIFEST_DIR/manifest.json" | python3 -c "import sys, json; print(json.load(sys.stdin)['version'])")/
    
    # 更新符号链接
    ln -sfn /opt/robot/releases/v\$(cat /opt/robot/releases/*/manifest.json | python3 -c "import sys, json; print(json.load(sys.stdin)['version'])") /opt/robot/current
    
    # 复制配置文件
    cp /opt/robot/current/config/*.toml /etc/robot/
    
    # 复制 systemd 服务文件
    cp /opt/robot/current/systemd/*.service /etc/systemd/system/
    systemctl daemon-reload
    
    # 启动服务
    systemctl start robotd mediad configd padd btd
    
    # 清理
    rm -rf /tmp/\$MANIFEST_DIR /tmp/$(basename "$PACKAGE")
    
    echo "Update completed successfully!"
EOF

echo "Deployment completed!"
```

### 使用部署脚本

```bash
# 给脚本执行权限
chmod +x scripts/deploy.sh

# 部署到机器人
./scripts/deploy.sh 192.168.1.100 update-v1.2.3-signed.tar.gz
```

## 8. CI/CD 集成

### GitHub Actions 配置

创建 `.github/workflows/release.yml`：

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Install Rust
      uses: actions-rs/toolchain@v1
      with:
        toolchain: stable
        target: aarch64-unknown-linux-gnu
        override: true
    
    - name: Install dependencies
      run: |
        sudo apt-get update
        sudo apt-get install -y gcc-aarch64-linux-gnu g++-aarch64-linux-gnu
    
    - name: Build
      run: |
        cargo build --release --target aarch64-unknown-linux-gnu
    
    - name: Package
      run: |
        VERSION=${GITHUB_REF#refs/tags/v}
        ./scripts/package-update.sh $VERSION
    
    - name: Sign
      run: |
        # 从 secrets 获取私钥
        echo "${{ secrets.UPDATE_PRIVATE_KEY }}" > keys/update.key
        chmod 600 keys/update.key
        ./scripts/sign-update.sh update-v${GITHUB_REF#refs/tags/v}.tar.gz
    
    - name: Upload artifact
      uses: actions/upload-artifact@v3
      with:
        name: update-package
        path: update-v*-signed.tar.gz
    
    - name: Create Release
      uses: softprops/action-gh-release@v1
      with:
        files: update-v*-signed.tar.gz
      env:
        GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 9. 故障排查

### 常见问题

#### 1. 交叉编译失败

```bash
# 错误：找不到 linker
error: linker `aarch64-linux-gnu-gcc` not found

# 解决：安装交叉编译工具链
sudo apt-get install gcc-aarch64-linux-gnu
```

#### 2. 依赖库缺失

```bash
# 错误：找不到 libssl
error: could not find system library 'openssl'

# 解决：安装 ARM64 版本的库
sudo apt-get install libssl-dev:arm64
```

#### 3. 服务启动失败

```bash
# 检查服务状态
systemctl status robotd

# 查看日志
journalctl -u robotd -f

# 手动运行测试
/opt/robot/current/robotd --test
```

#### 4. 更新失败

```bash
# 检查更新日志
cat /var/log/microduck-update.log

# 手动回滚
ln -sfn /opt/robot/backup-20240115-103000 /opt/robot/current
systemctl restart robotd mediad configd padd btd
```

## 总结

Microduck 的部署流程包括：

1. **环境搭建**: 安装 Rust、交叉编译工具链
2. **构建**: 编译 ARM64 版本
3. **打包**: 创建更新包，生成 manifest
4. **签名**: 使用 Ed25519 签名验证
5. **部署**: 上传并安装到机器人
6. **CI/CD**: 自动化构建和发布

这个流程确保每次部署都是安全、可靠、可追溯的。
