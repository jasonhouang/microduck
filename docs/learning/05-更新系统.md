# OTA 更新系统

## 概述

Microduck 实现了一个完整的 OTA (Over-The-Air) 更新系统，支持远程固件更新、版本管理、自动回滚和健康检查。这个系统确保机器人能够安全地接收新固件，并在更新失败时自动恢复到之前的版本。

### 更新状态机

```rust
enum UpdateState {
    Idle,
    Checking,
    Downloading { progress: f32 },
    Verifying,
    Installing,
    Restarting,
    HealthCheck,
    Committing,
    RollingBack,
    Failed(String),
}

struct UpdateManager {
    state: UpdateState,
    current_version: String,
    target_version: Option<String>,
    update_url: String,
    health_check_timeout: Duration,
}

impl UpdateManager {
    fn update_loop(&mut self) {
        loop {
            match self.state {
                UpdateState::Idle => {
                    // 等待更新触发
                    if self.should_check_update() {
                        self.state = UpdateState::Checking;
                    }
                }
                UpdateState::Checking => {
                    match self.check_for_update() {
                        Ok(Some(update)) => {
                            self.target_version = Some(update.version);
                            self.state = UpdateState::Downloading { progress: 0.0 };
                        }
                        Ok(None) => {
                            self.state = UpdateState::Idle;
                        }
                        Err(e) => {
                            self.state = UpdateState::Failed(e.to_string());
                        }
                    }
                }
                UpdateState::Downloading { progress } => {
                    match self.download_update(progress) {
                        Ok(()) => {
                            self.state = UpdateState::Verifying;
                        }
                        Err(e) => {
                            self.state = UpdateState::Failed(e.to_string());
                        }
                    }
                }
                UpdateState::Verifying => {
                    match self.verify_update() {
                        Ok(()) => {
                            self.state = UpdateState::Installing;
                        }
                        Err(e) => {
                            self.state = UpdateState::Failed(e.to_string());
                        }
                    }
                }
                UpdateState::Installing => {
                    match self.install_update() {
                        Ok(()) => {
                            self.state = UpdateState::Restarting;
                        }
                        Err(e) => {
                            self.state = UpdateState::RollingBack;
                        }
                    }
                }
                UpdateState::Restarting => {
                    match self.restart_services() {
                        Ok(()) => {
                            self.state = UpdateState::HealthCheck;
                        }
                        Err(e) => {
                            self.state = UpdateState::RollingBack;
                        }
                    }
                }
                UpdateState::HealthCheck => {
                    match self.perform_health_check() {
                        Ok(()) => {
                            self.state = UpdateState::Committing;
                        }
                        Err(e) => {
                            self.state = UpdateState::RollingBack;
                        }
                    }
                }
                UpdateState::Committing => {
                    match self.commit_update() {
                        Ok(()) => {
                            self.current_version = self.target_version.take().unwrap();
                            self.state = UpdateState::Idle;
                        }
                        Err(e) => {
                            self.state = UpdateState::Failed(e.to_string());
                        }
                    }
                }
                UpdateState::RollingBack => {
                    match self.rollback_update() {
                        Ok(()) => {
                            self.state = UpdateState::Idle;
                        }
                        Err(e) => {
                            self.state = UpdateState::Failed(e.to_string());
                        }
                    }
                }
                UpdateState::Failed(ref e) => {
                    tracing::error!("Update failed: {}", e);
                    // 等待重试或手动干预
                    std::thread::sleep(Duration::from_secs(60));
                    self.state = UpdateState::Idle;
                }
            }
            
            std::thread::sleep(Duration::from_secs(1));
        }
    }
}
```

## 3. 签名验证

### 签名算法

使用 Ed25519 签名算法，确保更新包的完整性和真实性。

```rust
use ed25519_dalek::{Verifier, VerifyingKey, Signature};

struct UpdateVerifier {
    public_key: VerifyingKey,
}

impl UpdateVerifier {
    fn verify_manifest(&self, manifest: &[u8], signature: &[u8]) -> Result<()> {
        let sig = Signature::from_slice(signature)?;
        self.public_key.verify(manifest, &sig)?;
        Ok(())
    }
    
    fn verify_file(&self, file_path: &Path, expected_hash: &str) -> Result<()> {
        let content = std::fs::read(file_path)?;
        let actual_hash = format!("{:x}", Sha256::digest(&content));
        
        if actual_hash != expected_hash {
            return Err(anyhow!("Hash mismatch for {:?}", file_path));
        }
        
        Ok(())
    }
}
```

## 4. 版本管理

### 版本号规范

使用语义化版本 (Semantic Versioning)：

```
MAJOR.MINOR.PATCH

MAJOR: 不兼容的 API 变更
MINOR: 向后兼容的功能新增
PATCH: 向后兼容的问题修正
```

### 版本比较

```rust
struct Version {
    major: u32,
    minor: u32,
    patch: u32,
}

impl Version {
    fn parse(version_str: &str) -> Result<Self> {
        let parts: Vec<&str> = version_str.trim_start_matches('v').split('.').collect();
        if parts.len() != 3 {
            return Err(anyhow!("Invalid version format"));
        }
        
        Ok(Self {
            major: parts[0].parse()?,
            minor: parts[1].parse()?,
            patch: parts[2].parse()?,
        })
    }
    
    fn is_compatible_with(&self, other: &Version) -> bool {
        // 主版本号相同表示兼容
        self.major == other.major
    }
    
    fn is_newer_than(&self, other: &Version) -> bool {
        if self.major != other.major {
            return self.major > other.major;
        }
        if self.minor != other.minor {
            return self.minor > other.minor;
        }
        self.patch > other.patch
    }
}

impl Ord for Version {
    fn cmp(&self, other: &Self) -> Ordering {
        match self.major.cmp(&other.major) {
            Ordering::Equal => {}
            ord => return ord,
        }
        match self.minor.cmp(&other.minor) {
            Ordering::Equal => {}
            ord => return ord,
        }
        self.patch.cmp(&other.patch)
    }
}
```

### 版本数据库

```rust
struct VersionDatabase {
    versions: Vec<VersionInfo>,
    current_version: Version,
}

struct VersionInfo {
    version: Version,
    release_date: DateTime<Utc>,
    changelog: String,
    download_url: String,
    signature: Vec<u8>,
    min_supported_version: Version,
}

impl VersionDatabase {
    fn get_latest_version(&self) -> Option<&VersionInfo> {
        self.versions
            .iter()
            .filter(|v| v.version.is_compatible_with(&self.current_version))
            .max_by(|a, b| a.version.cmp(&b.version))
    }
    
    fn can_upgrade_to(&self, target: &Version) -> bool {
        // 检查目标版本是否高于当前版本
        target.is_newer_than(&self.current_version)
    }
    
    fn can_downgrade_to(&self, target: &Version) -> bool {
        // 检查目标版本是否在支持范围内
        target >= &self.current_version // 示例逻辑
    }
}
```

```rust
impl HealthChecker {
    fn perform_health_check(&self) -> Result<()> {
        let start = Instant::now();
        
        for check in &self.checks {
            if start.elapsed() > self.timeout {
                return Err(anyhow!("Health check timeout"));
            }
            
            match check.check() {
                Ok(()) => {
                    tracing::info!("Health check passed: {}", check.name());
                }
                Err(e) => {
                    if check.critical() {
                        tracing::error!("Critical health check failed: {}: {}", check.name(), e);
                        return Err(e);
                    } else {
                        tracing::warn!("Non-critical health check failed: {}: {}", check.name(), e);
                    }
                }
            }
        }
        
        Ok(())
    }
}
```

## 6. 回滚机制

### 回滚策略

```rust
struct RollbackManager {
    release_dir: PathBuf,
    current_symlink: PathBuf,
    backup_dir: PathBuf,
}

impl RollbackManager {
    fn create_backup(&self) -> Result<()> {
        // 备份当前版本
        let current_target = std::fs::read_link(&self.current_symlink)?;
        let backup_path = self.backup_dir.join("previous");
        
        if backup_path.exists() {
            std::fs::remove_dir_all(&backup_path)?;
        }
        
        std::fs::copy(&current_target, &backup_path)?;
        tracing::info!("Created backup of current version");
        
        Ok(())
    }
    
    fn rollback(&self) -> Result<()> {
        let backup_path = self.backup_dir.join("previous");
        
        if !backup_path.exists() {
            return Err(anyhow!("No backup available for rollback"));
        }
        
        // 切换符号链接
        let temp_link = self.current_symlink.with_extension("tmp");
        std::os::unix::fs::symlink(&backup_path, &temp_link)?;
        std::fs::rename(&temp_link, &self.current_symlink)?;
        
        tracing::info!("Rolled back to previous version");
        
        // 重启服务
        self.restart_services()?;
        
        Ok(())
    }
    
    fn restart_services(&self) -> Result<()> {
        let services = vec!["robotd", "mediad", "configd", "padd", "btd"];
        
        for service in services {
            Command::new("systemctl")
                .args(&["restart", service])
                .status()?;
        }
        
        Ok(())
    }
}
```

### 回滚触发条件

```rust
struct RollbackTrigger {
    max_retries: u32,
    retry_count: u32,
    health_check_failures: u32,
    max_health_check_failures: u32,
}

impl RollbackTrigger {
    fn should_rollback(&mut self, health_check_result: &Result<()>) -> bool {
        match health_check_result {
            Ok(()) => {
                self.health_check_failures = 0;
                false
            }
            Err(_) => {
                self.health_check_failures += 1;
                if self.health_check_failures >= self.max_health_check_failures {
                    tracing::error!("Too many health check failures, triggering rollback");
                    return true;
                }
                
                self.retry_count += 1;
                if self.retry_count >= self.max_retries {
                    tracing::error!("Too many retries, triggering rollback");
                    return true;
                }
                
                false
            }
        }
    }
}
```

## 8. 更新日志

### 日志记录

```rust
struct UpdateLogger {
    log_path: PathBuf,
}

impl UpdateLogger {
    fn log_update_start(&self, version: &str) -> Result<()> {
        let entry = UpdateLogEntry {
            timestamp: Utc::now(),
            event: "update_start".to_string(),
            version: version.to_string(),
            details: None,
        };
        self.write_entry(&entry)
    }
    
    fn log_update_success(&self, version: &str) -> Result<()> {
        let entry = UpdateLogEntry {
            timestamp: Utc::now(),
            event: "update_success".to_string(),
            version: version.to_string(),
            details: None,
        };
        self.write_entry(&entry)
    }
    
    fn log_update_failure(&self, version: &str, error: &str) -> Result<()> {
        let entry = UpdateLogEntry {
            timestamp: Utc::now(),
            event: "update_failure".to_string(),
            version: version.to_string(),
            details: Some(error.to_string()),
        };
        self.write_entry(&entry)
    }
    
    fn log_rollback(&self, from_version: &str, to_version: &str) -> Result<()> {
        let entry = UpdateLogEntry {
            timestamp: Utc::now(),
            event: "rollback".to_string(),
            version: from_version.to_string(),
            details: Some(format!("Rolled back to {}", to_version)),
        };
        self.write_entry(&entry)
    }
    
    fn write_entry(&self, entry: &UpdateLogEntry) -> Result<()> {
        let mut file = OpenOptions::new()
            .create(true)
            .append(true)
            .open(&self.log_path)?;
        
        let json = serde_json::to_string(entry)?;
        writeln!(file, "{}", json)?;
        
        Ok(())
    }
}

#[derive(Serialize)]
struct UpdateLogEntry {
    timestamp: DateTime<Utc>,
    event: String,
    version: String,
    details: Option<String>,
}
```

## 总结

Microduck 的 OTA 更新系统是一个完整的、安全的、可靠的固件更新解决方案：

1. **安全性**: Ed25519 签名验证，确保更新包完整性和真实性
2. **可靠性**: 健康检查和自动回滚机制，确保更新失败时能恢复
3. **灵活性**: 支持版本管理、依赖检查、配置管理
4. **可观测性**: 完整的更新日志，便于问题追踪和审计
5. **自动化**: 支持自动检查更新、自动下载、自动安装

这个系统确保机器人能够安全地接收新功能和修复，同时最大限度地降低更新风险。
