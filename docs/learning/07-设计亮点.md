# 设计亮点

## 概述

Microduck 项目在设计上体现了多个创新点和最佳实践，涵盖了硬件选型、软件架构、控制算法、安全机制等多个方面。本文档将总结项目的核心设计亮点，帮助理解这些设计决策背后的思考。

## 1. 单总线多设备架构

### 设计亮点

Microduck 采用 **单 UART 总线** 连接所有 15 个舵机和 1 个 IMU，这是一个大胆而精妙的设计决策。

### 技术实现

```
/dev/ttyS2 (1 Mbps)
    │
    ├── ID 0-14: 15个 XL330 舵机
    │
    └── ID 200: imu_to_dxl v2 转接板
              └── LSM6DSV16X IMU (SPI)
```

### 优势

1. **硬件简化**
   - 仅需 1 个 UART 接口
   - 减少布线复杂度
   - 降低硬件成本

2. **同步性保证**
   - 所有传感器数据在同一时刻采集
   - 避免多总线时序对齐问题
   - 控制算法获得一致的状态快照

3. **确定性延迟**
   - 总线访问延迟可预测
   - 便于实时性分析
   - 50Hz 控制循环稳定运行

### 挑战与解决

**挑战**: 带宽限制
- 15 个舵机 + 1 个 IMU = 16 个设备
- 每次通信需要约 2ms
- 50Hz 周期 = 20ms，通信占比 10%

**解决方案**:
- 使用 Dynamixel 协议的高效同步读写
- 批量读取所有设备状态（1 次事务）
- 批量写入所有目标位置（1 次事务）

### 代码示例

```rust
// 一次读取所有设备
let sensors = bus.sync_read_all()?;
// sensors.imu: ImuData
// sensors.joints: [JointState; 15]

// 一次写入所有目标
bus.sync_write_all(&targets)?;
```

## 2. Rust 借用检查器实现安全保证

### 设计亮点

利用 Rust 的 **所有权和借用检查器** 在编译期保证控制循环的安全性，而非依赖运行时检查。

### 核心思想

```rust
// 控制循环拥有唯一的 IO 访问权
struct ControlLoop {
    bus: DynamixelBus,  // 独占所有权
    policy: Policy,
    safety: SafetyChecker,
}

impl ControlLoop {
    fn run(&mut self) {
        loop {
            // 1. 读取传感器（独占访问）
            let sensors = self.bus.read_all()?;
            
            // 2. 策略推理（纯计算，无 IO）
            let action = self.policy.infer(&sensors);
            
            // 3. 安全检查（纯计算）
            let safe_action = self.safety.check(&action, &sensors);
            
            // 4. 写入执行器（独占访问）
            self.bus.write_all(&safe_action)?;
        }
    }
}
```

### 安全保证

1. **编译期互斥**
   - `DynamixelBus` 被 `ControlLoop` 独占
   - 其他组件无法直接访问硬件
   - 避免并发访问导致的冲突

2. **零成本抽象**
   - 所有权检查在编译期完成
   - 运行时无额外开销
   - 性能与手写 C 代码相当

3. **类型安全**
   - 传感器数据类型化
   - 动作指令类型化
   - 避免类型错误导致的硬件损坏

### 对比传统方案

| 方案 | 安全检查时机 | 运行时开销 | 可靠性 |
|------|-------------|-----------|--------|
| C/C++ + 互斥锁 | 运行时 | 高 | 依赖程序员 |
| Python + GIL | 运行时 | 极高 | 低 |
| **Rust + 借用检查** | **编译期** | **零** | **高** |

## 3. 策略热切换机制

### 设计亮点

```
│  │  - 已加载的策略列表         │   │
│  │  - 策略元数据               │   │

│                                     │

└─────────────────────────────────────┘
```

### 实现细节

```rust
struct PolicyManager {
    active_policy: Box<dyn Policy>,
    registry: PolicyRegistry,
    transition_state: Option<TransitionState>,
}

impl PolicyManager {
    fn switch_policy(&mut self, new_policy: &str) -> Result<()> {
        // 1. 加载新策略
        let policy = self.registry.load(new_policy)?;
        
        // 2. 创建过渡状态
        self.transition_state = Some(TransitionState {
            old_policy: std::mem::replace(&mut self.active_policy, policy),
            start_time: Instant::now(),
            duration: Duration::from_millis(500),
        });
        
        Ok(())
    }
    
    fn infer(&mut self, sensors: &Sensors) -> Action {
        if let Some(ref mut transition) = self.transition_state {
            // 过渡期间：混合两个策略的输出
            let elapsed = transition.start_time.elapsed();
            let alpha = (elapsed.as_secs_f32() / transition.duration.as_secs_f32()).min(1.0);
            
            let old_action = transition.old_policy.infer(sensors);
            let new_action = self.active_policy.infer(sensors);
            
            let blended = blend_actions(&old_action, &new_action, alpha);
            
            if alpha >= 1.0 {
                // 过渡完成
                self.transition_state = None;
            }
            
            blended
        } else {
            // 正常模式
            self.active_policy.infer(sensors)
        }
    }
}
```

### 应用场景

1. **行为切换**
   - 行走 → 站立 → 坐下
   - 正常行走 → 跳舞模式
   - 自主导航 → 遥控模式

2. **在线学习**
   - 加载新训练的策略
   - 无需停机即可更新
   - 平滑过渡避免抖动

3. **故障恢复**
   - 检测到异常策略
   - 自动切换到安全策略
   - 保证系统稳定性

```rust
struct SafetySystem {
    hardware_protection: HardwareProtection,
    joint_protection: JointProtection,
    behavior_protection: BehaviorProtection,
    system_protection: SystemProtection,
}

impl SafetySystem {
    fn check(&self, action: &Action, sensors: &Sensors) -> Result<Action> {
        // Layer 1: 硬件级
        let action = self.hardware_protection.check(action, sensors)?;
        
        // Layer 2: 关节级
        let action = self.joint_protection.check(action, sensors)?;
        
        // Layer 3: 行为级
        let action = self.behavior_protection.check(action, sensors)?;
        
        // Layer 4: 系统级
        self.system_protection.check(action, sensors)?;
        
        Ok(action)
    }
}

struct JointProtection {
    position_limits: [PositionLimits; 15],
    velocity_limits: [VelocityLimits; 15],
    torque_limits: [TorqueLimits; 15],
    temperature_limits: [TemperatureLimits; 15],
}

impl JointProtection {
    fn check(&self, action: &Action, sensors: &Sensors) -> Result<Action> {
        let mut safe_action = action.clone();
        
        for i in 0..15 {
            // 位置限位
            if action.positions[i] < self.position_limits[i].min {
                safe_action.positions[i] = self.position_limits[i].min;
            }
            if action.positions[i] > self.position_limits[i].max {
                safe_action.positions[i] = self.position_limits[i].max;
            }
            
            // 速度限制
            let velocity = (action.positions[i] - sensors.joints[i].position) / DT;
            if velocity.abs() > self.velocity_limits[i].max {
                let max_delta = self.velocity_limits[i].max * DT;
                safe_action.positions[i] = sensors.joints[i].position 
                    + velocity.signum() * max_delta;
            }
            
            // 温度保护
            if sensors.joints[i].temperature > self.temperature_limits[i].max {
                // 降低该关节的运动幅度
                safe_action.positions[i] = sensors.joints[i].position * 0.9 
                    + action.positions[i] * 0.1;
            }
        }
        
        Ok(safe_action)
    }
}
```

### 优势

1. **冗余保护**
   - 单层失效不会导致系统崩溃
   - 多层检查提高可靠性

2. **细粒度控制**
   - 每层可独立配置
   - 便于调试和优化

3. **可追溯性**
   - 记录每层安全检查结果
   - 便于故障分析

### 动态加载

```rust
struct PluginManager {
    plugins: HashMap<String, Box<dyn Plugin>>,
    load_order: Vec<String>,
}

impl PluginManager {
    fn load_plugin(&mut self, path: &str) -> Result<()> {
        // 动态加载共享库
        let lib = libloading::Library::new(path)?;
        
        // 获取插件创建函数
        let create_fn: libloading::Symbol<fn() -> Box<dyn Plugin>> = 
            unsafe { lib.get(b"create_plugin")? };
        
        // 创建插件实例
        let plugin = create_fn();
        
        // 解析依赖
        self.resolve_dependencies(&plugin)?;
        
        // 注册插件
        let name = plugin.name().to_string();
        self.plugins.insert(name.clone(), plugin);
        self.load_order.push(name);
        
        Ok(())
    }
    
    fn update_all(&mut self, sensors: &Sensors, action: &mut Action) -> Result<()> {
        for name in &self.load_order {
            if let Some(plugin) = self.plugins.get_mut(name) {
                plugin.update(sensors, action)?;
            }
        }
        Ok(())
    }
}
```

```rust
impl SharedMemoryBuffer {

        unsafe {
            std::ptr::copy_nonoverlapping(

                self.ptr,
                data.len()

        }
```

```rust
use std::arch::aarch64::*;

fn vector_add_simd(a: &[f32; 15], b: &[f32; 15]) -> [f32; 15] {
    let mut result = [0.0f32; 15];
    
    unsafe {
        // 处理前 12 个元素（3 个 float32x4）
        for i in (0..12).step_by(4) {
            let va = vld1q_f32(&a[i]);
            let vb = vld1q_f32(&b[i]);
            let vr = vaddq_f32(va, vb);
            vst1q_f32(&mut result[i], vr);
        }
        
        // 处理剩余 3 个元素
        for i in 12..15 {
            result[i] = a[i] + b[i];
        }
    }
    
    result
}
```

## 7. 优雅的降级策略

### 设计亮点

当系统遇到异常时，能够 **优雅降级** 而非直接崩溃，保证基本功能可用。

### 降级策略

```rust

    Normal,           // 正常运行
    Degraded,         // 降级模式
    SafeMode,         // 安全模式
    EmergencyStop,    // 紧急停止
}

struct DegradationManager {
    state: SystemState,
    failed_components: HashSet<String>,
}

impl DegradationManager {
    fn on_component_failure(&mut self, component: &str) {
        self.failed_components.insert(component.to_string());
        
        // 根据故障组件决定降级策略
        match component {
            "camera" => {
                // 摄像头故障：禁用视觉功能，保持运动能力
                self.state = SystemState::Degraded;
                self.disable_vision_features();
            }
            "imu" => {
                // IMU 故障：切换到安全模式，缓慢停止
                self.state = SystemState::SafeMode;
                self.slow_stop();

                // 单个关节故障：禁用该关节，调整姿态

                self.disable_joint(3);
                self.recalculate_pose();

                // 通信故障：进入自主安全模式
                self.state = SystemState::SafeMode;
                self.autonomous_safety();
            }
            _ => {}
        }
    }

    }
    
    fn slow_stop(&mut self) {

    }
```

### 降级矩阵

| 故障组件 | 降级策略 | 保留功能 | 失去功能 |

   - 平滑过渡到安全状态

3. **可维护性**

```rust
use tracing::{info, warn, error, instrument};
use tracing_subscriber::{fmt, EnvFilter};

#[instrument(skip(sensors))]
fn control_loop_iteration(sensors: &Sensors) -> Result<Action> {

        imu_gyro = ?sensors.imu.gyro,

    tracing::info!(
        duration_ms = duration.as_secs_f32() * 1000.0,
        cpu_usage = get_cpu_usage(),
        memory_usage = get_memory_usage(),
        "Control loop completed"
    );
    
    Ok(action)
}
```

```rust
struct DiagnosticServer {

impl DiagnosticServer {
    fn handle_client(&self, mut stream: TcpStream) {
        let request: DiagnosticRequest = serde_json::from_reader(&stream).unwrap();
        
        let response = match request {
            DiagnosticRequest::GetStatus => {
                DiagnosticResponse::Status {
                    uptime: get_uptime(),
                    cpu_usage: get_cpu_usage(),
                    memory_usage: get_memory_usage(),
                    active_plugins: get_active_plugins(),
                }
            }
            DiagnosticRequest::GetLogs { level, limit } => {
                DiagnosticResponse::Logs {
                    entries: get_recent_logs(level, limit),
                }
            }
            DiagnosticRequest::GetMetrics => {
                DiagnosticResponse::Metrics {
                    control_loop_time: get_control_loop_metrics(),
                    sensor_rates: get_sensor_rates(),
                    error_counts: get_error_counts(),
                }
            }
            DiagnosticRequest::RunTest { test_name } => {
                DiagnosticResponse::TestResult {
                    result: run_diagnostic_test(&test_name),
                }
            }
        };
        
        serde_json::to_writer(&stream, &response).unwrap();
    }
}
```
