# 声音数据采集指南

## 目标
改进宠物检测模型，减少误报，提高准确性。

## 当前问题
- 训练数据太少
- 背景噪音样本不足
- 模型把环境噪音误认为叫声/哭声

## 采集设备
使用实际的开发板（radxa-zero3）录音，确保训练数据和推理条件一致。

## 采集方法

### 1. 呱呱叫样本 (data/quack/)
需要 30-50 个不同的呱呱叫样本：
- 近距离（10-30cm）：10 个
- 中距离（50-100cm）：10 个
- 远距离（1-2m）：10 个
- 不同音量（轻柔、正常、大声）：各 5-10 个
- 不同音调（高音、低音）：各 5-10 个

### 2. 婴儿哭声样本 (data/cry/)
需要 30-50 个不同的哭声样本：
- 真实婴儿哭声（可以从网上下载或录制）
- 模拟哭声（用嘴模仿）
- 不同距离和音量
- 注意：不要只用模拟哭声，否则模型无法识别真实哭声

### 3. 背景噪音样本 (data/normal/)
需要 50-100 个背景噪音样本（最重要！）：
- 安静环境（房间 silence）：10 个
- 人说话声（中文、英文）：15 个
- 电视/音乐声：10 个
- 键盘敲击声：10 个
- 脚步声：5 个
- 其他家电声（风扇、空调）：10 个
- 室外噪音（鸟叫、车声）：10 个
- 混合噪音：10 个

## 录制脚本

使用开发板直接录制：

```bash
# 录制一个样本（10秒）
arecord -D plughw:i2saudio,0 -f S16_LE -r 16000 -c 1 -d 10 sample.wav

# 批量录制（每个样本间隔 2 秒）
for i in {1..10}; do
  arecord -D plughw:i2saudio,0 -f S16_LE -r 16000 -c 1 -d 10 "sample_$i.wav"
  sleep 2
done
```

## 数据增强

录制完成后，使用 Python 脚本进行数据增强：
- 变调（±10%, ±20%）
- 变速（0.9x, 1.1x）
- 变音量（-6dB, +6dB）
- 添加轻微噪音

这样可以从 30 个原始样本生成 150+ 个训练样本。

## 验证方法

1. 采集完数据后，先可视化检查频谱
2. 训练模型后，用测试集验证
3. 在实际环境中测试，记录误报和漏报
